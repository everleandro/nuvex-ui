# Sponsoring Nuvex UI

Support the ongoing development of Nuvex UI and help fund the work behind a modern, production-ready Vue 3 component framework.

Nuvex UI is built to help teams ship more consistent interfaces with less friction. Sponsorship helps sustain the project through component development, documentation, testing, accessibility work, and long-term maintenance.

## Ways to Support

- GitHub Sponsors: https://github.com/sponsors/everleandro
- Open source partnerships and product collaborations
- Sponsorship of specific roadmap items or feature areas
- Commercial support for teams integrating Nuvex UI in production

## What Sponsorship Helps Fund

- new component and pattern development
- design system improvements and theming work
- documentation, examples, and onboarding materials
- automation, testing, and release quality
- performance, accessibility, and maintenance improvements
- infrastructure and project tooling

## Why Support the Project

Your support helps keep the framework healthy, well-documented, and aligned with real product needs. Whether you are using Nuvex UI in a client project, an internal product, or a design system initiative, sponsorship directly contributes to its long-term sustainability.

## Contact

For sponsorships, partnerships, or commercial collaboration inquiries, please open a sponsorship issue in this repository or reach out through the GitHub Sponsors profile linked above.
